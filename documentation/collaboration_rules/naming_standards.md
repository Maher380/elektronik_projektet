The following work types are currently identified
when creating a task or a branch, please include that tag in the title.

* feature/ — new functionality
* fix/ — fixes for broken behavior
* docs/ — documentation-only work
* experiment/ — exploratory work not meant to be permanent
* refactor/ — internal code cleanup without changing behavior
* test/ — test-only changes
* chore/ — maintenance, refactors, tooling, dependency updates
* release/ — preparing a release
* ci/ — pipeline or automation changes
